Detailed Description

E3AP Control Response structure.

The answer to a dApp control or an xApp control that asked for one (request_ack). The RAN sends it for a dApp control, the dApp for an xApp control. It also carries the refusals the RAN makes before a Service Model sees a control, whether the control asked for an answer or not.
