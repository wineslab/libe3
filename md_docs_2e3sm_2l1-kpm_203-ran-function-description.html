Telemetry identifiers

General

A telemetry identifier names one stream of the service model. The dApp lists the identifiers in the SUBSCRIPTION REQUEST message. The E3 Agent grants them as clause 6.6.2 defines. Each identifier maps to one field of the INDICATION DATA IE, of the CELL DATA IE or of the UE DATA IE.

The identifiers are allocated as follows.

  • 1 to 79: the identifiers of clauses 7.3.2 to 7.3.4.
  • 80 to 999: reserved. An E3 Agent shall not list them. A dApp shall not request them.
  • 1000 to 65535: additional identifiers. Clause 7.3.5 allocates 1000. The other values are reserved.

The tables of clauses 7.3.2 to 7.3.5 give, for each identifier, the name of the stream, the scope, the data type in the stream descriptor, and the meaning. The name of the stream is the JSON key of its field and the streamId of its stream descriptor. The ASN.1 field of each identifier and its range are given in clause 8.2.

Additional identifiers

Table: Additional telemetry identifiers

ID Stream Scope Data type Path Description
1000 valid_symbol_mask Cell uint16 shared Bit map of the uplink symbols of the slot in the cell. Bit s (value 2^s) is set when OFDM symbol s is an uplink symbol.

The validSymbolMask follows the TDD configuration of the cell. All bits are set for FDD and for a slot that is uplink only. In a slot that mixes downlink and uplink, the downlink and guard symbols have their bit clear. The shared memory streams of identifiers 1 and 44 hold every symbol of their range, whatever the mask. In a mixed slot, the samples of a downlink symbol hold the transmit signal of the RAN node that leaks into its receiver. A dApp shall ignore the samples of a symbol whose bit is clear. Bits 14 and 15 are not used. A dApp that receives no validSymbolMask for a cell should treat every symbol of the slot as an uplink symbol.

Examples with a normal CP: 0x3FFF for an uplink slot; 0x3000 for a slot with 10 downlink, 2 guard and 2 uplink symbols. With an extended CP the slot has 12 symbols and an uplink slot gives 0x0FFF.
