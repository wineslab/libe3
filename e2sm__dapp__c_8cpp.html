Detailed Description

C API of the E2SM-DAPP codec, implemented on top of the C++ one.

Every function converts the C struct to its C++ counterpart (or back), calls pack() / unpack(), and maps the result to an e3_error_t. All memory handed to the caller is malloc'ed, so the free_* functions and plain free both work. Nothing here lets a C++ exception cross the C boundary.
